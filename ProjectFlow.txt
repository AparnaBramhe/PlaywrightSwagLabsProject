1. install required package: ajv library
https://www.npmjs.com/package/ajv

npm install ajv
 
-AJV stands for "Another Json Schema Validator"
-Ajv used for schema validation
- Ajv used one compile() where we can pass schema and 
this method returnd anonymous validator function which we can 
store into variable

let validate=ajv.compile(schema);

- in validate function we can provide actual server response which we
wanted to validate with respect to schema

-In real time you dont required to generate schema , it wil be 
provided in detialed design document by developers

How to create a Google App Password
1. Sign in to your Google account.
2. Open Google Account Security.
3. Make sure 2-Step Verification is enabled.
4. Find App passwords.
5. Click App passwords.
6. Sign in again if Google asks.
7. Enter an app name, for example:
   Playwright Email
8. Click Create.
9. Google will generate a 16-character App Password, something like:
   abcd efgh ijkl mnop
10. Copy it and use it in your application.

Gherkins Keyword
===================
#Author: your.email@your.domain.com
#Keywords Summary :
#Feature: List of scenarios.
#Scenario: Business rule through list of steps with arguments.
#Given: Some precondition step
#When: Some key actions
#Then: To observe outcomes or validation
#And,But: To enumerate more Given,When,Then steps
#Scenario Outline: List of steps for data-driven as an Examples and <placeholder>
#Examples: Container for s table
#Background: List of steps run before each of the scenarios
#""" (Doc Strings)
#| (Data Tables)
#@ (Tags/Labels):To group Scenarios
#<> (placeholder)
#""
## (Comments)
#Sample Feature Definition Template
@tag
Feature: Title of your feature
  I want to use this template for my feature file

  @tag1
  Scenario: Title of your scenario
    Given I want to write a step with precondition
    And some other precondition
    When I complete action
    And some other action
    And yet another action
    Then I validate the outcomes
    And check more outcomes

  @tag2
  Scenario Outline: Title of your scenario outline
    Given I want to write a step with <name>
    When I check for the <value> in step
    Then I verify the <status> in step

    Examples: 
      | name  | value | status  |
      | name1 |     5 | success |
      | name2 |     7 | Fail    |
