Schema validation
1. install required package: ajv library
https://www.npmjs.com/package/ajv

npm install ajv
 
-AJV stands for "Another Json Schema Validator"
-Ajv used for schema validation
- Ajv used one compile() where we can pass schema and 
this method returnd anonymous validator function which we can 
store into variable

let validate=ajv.compile(schema);

- in validate function we can provide actual server response which we
wanted to validate with respect to schema

-In real time you dont required to generate schema , it wil be 
provided in detialed design document by developers

Authentication: Validation of user : valid/invalid user
Authorization: Access control of valid user

Auth types:
  No Auth
    - If your request doesn’t require authorization, select No Auth.
  API Key
    - With API key auth, you send a key-value pair to the API 
    either in the request headers or query parameters.
  Bearer token
    - Bearer tokens enable requests to authenticate using an access key, 
    such as a JSON Web Token (JWT).
  JWT bearer
    - JWT, which stands for JSON Web Token, is an open standard 
    for securely sharing JSON data between parties. 
    - The data is encoded and digitally signed, which ensures its authenticity.
  Basic Auth
    - Basic authentication involves sending 
    a verified username and password with your request.
